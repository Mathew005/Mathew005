# Mathew Saju - Developer Portfolio

A high-performance, modular developer portfolio built with a "brutalist" aesthetic.

## Features
- **Modular Content**: Pages are written in Markdown (`.md`) and loaded dynamically via AJAX.
- **Brutalist Design**: Sharp corners, high contrast, and heavy shadows for a bold look.
- **Direct Sheet Backend**: Contact form saves messages directly to a Google Sheet.
- **Daily Aggregation**: Automated daily email summaries of all contact form submissions.
- **reCAPTCHA v3**: Built-in bot protection with a hidden badge.

## Tech Stack
- **Frontend**: Vanilla HTML5, CSS3, JavaScript (ES6+).
- **Markdown Parsing**: [Marked.js](https://marked.js.org/).
- **Backend**: Google Apps Script (Sheet + MailApp).

## Project Structure
- `index.html`: Main shell.
- `app.js`: Dynamic routing and form logic.
- `style.css`: Design tokens and component styles.
- `*.md`: Page content files.
- `README.md`: Project documentation.
